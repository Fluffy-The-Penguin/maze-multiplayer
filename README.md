# Maze Multiplayer

Standalone Vercel frontend for the AniTrack backend maze multiplayer API.

Backend default:

`https://anime-api-proxy.aryanpanwar.workers.dev`

API routes used:

- `POST /api/maze/rooms`
- `POST /api/maze/rooms/:code/join`
- `GET /api/maze/rooms/:code`
- `POST /api/maze/rooms/:code/move`
